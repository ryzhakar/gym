# N2-r6-06 — Verification

## Claim as surveyed
In an 84-undergraduate, 3-condition randomized comparison of what to front-load BEFORE the main programming task (worked-out example + scaffolding vs. faded worked-out example + scaffolding vs. worked-out example + faded scaffolding), providing non-faded metacognitive scaffolding together with either worked-out-example variant during this pre-training phase was the combination that best optimized cognitive load, self-efficacy and downstream programming problem-solving -- i.e. what precedes the main practice unit (the pre-training design), not only the main unit itself, measurably shapes skill/hour.

Abstract (the only text available): "84 undergraduate students were randomly assigned to one of three groups and each group received three different types of pre-training: 1) WOE (worked-out example) and metacognitive scaffolding, 2) faded WOE and metacognitive scaffolding, and 3) WOE and faded metacognitive scaffolding... The findings revealed that providing both cognitive scaffolding (i.e., WOE or faded WOE) and non-faded metacognitive scaffolding during the pre-training phase is effective for novice learners for optimizing cognitive load, promoting self-efficacy, and enhancing programming problem-solving skills."
