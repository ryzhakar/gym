# N5-r2-01 — Verification

## Claim as surveyed

"Across a chess sample graded by Elo rating from Grandmaster to Class C, the probability of finding a better-but-less-familiar solution rose monotonically with rating: .01 (Candidate Master, Elo 2150) to .12, .32, .64 (Grandmaster, Elo 2550) -- the elite margin inside an already-expert population is a graded dose-response, not a categorical cutoff." DOI 10.1016/j.cogpsych.2007.02.001. Surveyed S3 R2 O1.

## Primary text (quote, location)

Bilalić, McLeod & Gobet, "Inflexibility of experts—Reality or myth? Quantifying the Einstellung effect in chess masters," Cognitive Psychology 56(2), 2008 (accepted 2007-02, e-pub 2007-04-06). Full text read (Brunel University repository PDF via Unpaywall, submitted/accepted version).

Results, Experiment 1 (p.17 of PDF): "Rating had a significant effect (B = .013, S.E. = .005, Z = 8.4, p = .004) such that a decrease of 100 rating points reduced the odds of finding the shorter solution by a factor of 3.67. In other words, the probability of finding the shorter solution in the 2-solution problem for an average Grand Master (Elo 2550), International Master (Elo 2450), Master (Elo 2350), and Candidate Master (Elo 2150), was .64, .32, .12 and .01 respectively."

**Correction to the survey's framing.** The four regression-derived probabilities (.01/.12/.32/.64) are fit only on Group 1 — the four already-expert categories (Candidate Master through Grand Master, all 3–5.5 SDs above the population mean), n=6+6+11+11=34 (Table 1). Class C (average skill, 0 SD) is not part of this logistic regression and never attempted the 2-solution (primed) problem at all — Class C was Group 2, given only the 1-solution (extinction) problem, on which they scored 0% (Table 2). The claim's opening clause ("from Grandmaster to Class C") over-states the regression's population: the dose-response run is Candidate-Master-to-Grandmaster only, not down to Class C. The closing interpretive sentence — "the elite margin inside an already-expert population is a graded dose-response, not a categorical cutoff" — is accurate and is exactly what the regression shows; only the introductory range needs narrowing.

## Design facts

| field | value |
|---|---|
| design | quasi-experiment (rated players, unmanipulated Elo as continuous predictor) + logistic regression on binary solve/no-solve outcome |
| n | 34 (Group 1: GM=6, IM=6, Master=11, Candidate Master=11), think-aloud protocol, individually tested |
| population | tournament chess players (Oxford, Tuzla, Sarajevo clubs; Bosnian team championship 2003), adult, Elo-rated 3–5.5 SDs above population mean |
| instrument | single problem-solving trial (2-solution "critical" chess problem), think-aloud, timed to solution; unlimited time |
| delay-to-test | none — single-session, immediate, one trial per player |
