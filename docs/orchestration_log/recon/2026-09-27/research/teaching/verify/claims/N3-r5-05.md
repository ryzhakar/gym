# N3-r5-05 — Verification

## Claim as surveyed
Despite GPT-4 showing superior results explaining errors on synthetic/expert-judged benchmarks, GPT-4-generated error-message explanations outperformed conventional compiler error messages on time-to-fix in only 1 of 6 realistic debugging tasks. https://arxiv.org/abs/2409.18661.

## Primary text (quote, location)
Same PDF as N3-r5-04. Abstract: "we found that GPT-4 generated error messages outperformed conventional compiler error messages in only 1 of the 6 tasks, measured by students' time-to-fix each problem." Table 1, GCC-vs-GPT-4 rows, all 5 tasks with a valid comparison (flipped-assignment task excluded, no significant condition effect found by ANOVA): #const 4.93s p=0.893 (n.s.); "using a keyword as a name" 28.61s p=0.006 (significant, GCC slower ⇒ GPT-4 the one task where it beats GCC); missing parameter −15.08s p=0.021 (significant, but GCC is faster here, i.e. GPT-4 loses); missing curly brace 50.6s p=0.373 (n.s.); reassigning constant 6.28s p=0.996 (n.s.). Background claim ("superior results... on synthetic benchmarks") is sourced by the paper itself to prior work [22, 39, 48] cited in its Introduction, not measured in this study.

## Design facts
Same as N3-r5-04: within-subjects RCT, n=106, 6 C-debugging tasks, per-task one-way ANOVA + Tukey HSD on log time-to-fix, immediate outcome.
