# N5-r2-02 — Verification

## Claim as surveyed

"Under a stimulus manipulation that primed a familiar-but-suboptimal solution, players 3 SDs above average skill (Candidate Masters) solved the problem at 0%, statistically indistinguishable from average-skill (Class C) players also at 0%; the same manipulation left the standard, unprimed version of the problem solved at high rates by both groups." DOI 10.1016/j.cogpsych.2007.02.001. Surveyed S3 R2 O1.

## Primary text (quote, location)

Bilalić, McLeod & Gobet (2008), Cognitive Psychology 56(2). Full text read (Brunel repository PDF via Unpaywall).

Results, Experiment 1 (p.18–19 of PDF): "The performance of the Candidate Masters (3SDs above the average skill level) (0%) was the same as the performance of the Class C players (average skill level) (0%)."

Table 2 (p.55, verbatim): "Experiment 1. The percentage of players in Group 1 (experts) who found the optimal solution in the 2-solution (critical) or 1-solution (extinction) problems and the percentage of players in Group 2 (less skilful players) who found the solution in the 1-solution problem." Rows: Group 1 — Grand Master 100% (2-sol) / — ; International Master 50% (2-sol) / 100% (1-sol); Master 18% (2-sol) / 100% (1-sol); Candidate Master 0% (2-sol) / 100% (1-sol). Group 2 — Class A 63% (1-sol only); Class B 13% (1-sol only); Class C 0% (1-sol only). Table note: "The players in Group 2 were presented with the 1-solution (extinction) problem only."

## Design facts

| field | value |
|---|---|
| design | between-groups comparison, not a within-subject priming manipulation on a shared task |
| n | Candidate Master n=11 (Group 1); Class C n=8 (Group 2) — Table 1 |
| population | tournament chess players, Group 1 = "expert" band (3–5.5 SD above mean), Group 2 = weaker band (0–2 SD above mean) |
| instrument | Group 1 given the 2-solution ("primed"/critical) problem, with a 1-solution ("unprimed"/extinction) follow-up only for those who failed; Group 2 given the 1-solution problem only, never the 2-solution problem |
| delay-to-test | none — single session |

**The claim misstates the design and is contradicted by Table 2.** There was no single "stimulus manipulation" applied to both groups with a primed and an unprimed arm each group passed through. Candidate Masters (Group 1) attempted the *primed* 2-solution problem and scored 0%; those who failed it were then given the *unprimed* 1-solution follow-up and scored 100% (Table 2) — a high rate, as the claim says for "both groups" combined. But Class C (Group 2) never saw the primed 2-solution problem at all — Class C's *only* data point is 0% on the *unprimed* 1-solution problem itself (Table 2 note: "Group 2 were presented with the 1-solution (extinction) problem only"). So the claim's final clause — "the same manipulation left the standard, unprimed version of the problem solved at high rates by both groups" — is false for Class C: their unprimed-problem score was 0%, not high. The paper's own point in this passage is the opposite of what the claim implies: it uses Class C's baseline (unprimed) difficulty (0%) as a benchmark showing that Einstellung-impaired Candidate Masters (primed, 0%) perform *no better than players with no prior chess knowledge advantage even on the easier unprimed task* — i.e., the two 0% figures come from two different problems given to two different groups, not from the same manipulation's primed/unprimed arms replicated identically in each group. "Statistically indistinguishable" also overstates the paper's own language ("was the same as"), which reports a descriptive equivalence, not a reported significance test between the two groups.

## Grade (S R O, changed from survey? why)

S=3→1: the claim as written does not describe an experiment that occurred (no shared priming manipulation with a primed/unprimed arm run on both groups) — it is a misreading of a between-groups design, so the "evidence" it purports to describe does not exist in this form; the strongest defensible grade for the corrected fact (two different groups' scores on two different problems) is S3, but the claim itself is not a faithful description of that evidence.
R=2 (unchanged): chess, other skill domain.
O=1 (unchanged): immediate, no delay.

## Status: REFUTED

The numeric coincidence (Candidate Master 0% on the 2-solution problem; Class C 0% on the 1-solution problem) is real and directly quoted in the source, but the claim's causal frame — a single priming manipulation, run on both groups, with an unprimed arm solved at "high rates by both groups" — is not what the study did and is directly contradicted by Table 2 (Class C's unprimed score is 0%, not high; Class C was never given the primed problem). The claim should not be used as evidence for a within-subject priming effect at matched skill bands.
