## Primary text (quote, location)
Full text fetched: `https://arxiv.org/pdf/2601.20245v2` (12pp, pdftotext -layout).

Abstract (lines 15-21): "We conduct randomized experiments to study how developers gained mastery of a new asynchronous programming library with and without the assistance of AI. We find that AI use impairs conceptual understanding, code reading, and debugging abilities, without delivering significant efficiency gains on average. Participants who fully delegated coding tasks showed some productivity improvements, but at the cost of learning the library. We identify six distinct AI interaction patterns, three of which involve cognitive engagement and preserve learning outcomes."

Main-study efficiency result (Discussion, lines 1136-1137): "Contrary to our initial hypothesis, we did not observe a significant performance boost in task completion in our main study. While using AI improved the average completion time of the task, the improvement in efficiency was not significant in our study."

Delegation subgroup (line 1132-1135): the AI-delegation group "finished much faster than the control group (19.5 minutes vs 23 minutes), but this group only accounted for around 20% of the participants in the treatment group" — the claim's "productivity improvements" for full delegators, distinct from the null average effect.

Six-pattern typology (line 682-686): "we develop a typology of six AI interaction patterns... these six patterns yield different outcomes for both completion time and skill formation... high-scoring patterns generally involve more cognitive effort and less AI reliance" — quiz scores 65-86% (high-scoring, 3 patterns) vs 24-39% (low-scoring, 3 patterns), confirming "only some of six" preserved learning.

Note on a separate result not to conflate: Pilot Study D (n=20, line 474) found a *significant* efficiency gain (Cohen's d=1.11, p=0.03) — this is a pilot, superseded by the main study's null result quoted above. The claim correctly reflects the main study, not the pilot.

## Design facts
- Design: between-subjects randomized controlled experiment (line 331, 1121-1123).
- Main study n=52 (26 control / 26 AI-assistance), crowdworking platform; participants self-reported prior Python experience (line 370-371).
- Task: two coding tasks with the Trio async Python library, 35-min limit; treatment group had chat-based AI assistant access, control had web search + instructions only.
- Instrument: post-task quiz (7 Trio concepts), scored on Conceptual, Debugging, Code Reading item types; pre-registered rubric.
- Delay-to-test: quiz administered immediately after the task session in the same sitting — no delayed retest. O=1 (unaided performance immediately after), not O=2.
- Population: crowd workers with self-reported Python experience — adults, professional/CS-adjacent skill acquisition context.
