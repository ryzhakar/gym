# N1-r7-07 — Verification

## Claim as surveyed
"In a preregistered high-school RCT, unguardrailed GPT-4 access raised assisted practice-problem scores by 48% but lowered the immediately following unassisted, closed-book exam score by 17% relative to a no-AI control; a guardrailed variant (hints, not answers) raised practice scores by 127% with no exam-score penalty -- assisted-session performance and unaided performance moved in opposite directions under the ungated condition, so a trainer that measures only in-session (assisted) output can certify a skill gain that unaided testing shows is a loss." (DOI 10.1073/pnas.2422633122)
