# N7-r1-01 — Verification

## Claim as surveyed

"Ungated GPT-4 practice access raised practice-problem scores but produced a roughly -0.19 SD unassisted-exam deficit relative to a no-AI control, in a cluster-RCT of 839 Turkish high-schoolers." DOI 10.1073/pnas.2422633122. Surveyed S3 R1 O1.

## Primary text (quote, location)

Bastani et al., PNAS 122(26), 2025. Full text read via PMC (PMC12232635; PDF blocked by NCBI proof-of-work challenge, HTML full text extracted instead — page numbers unavailable in this rendering, section names used).

Table 1 (Main Results section): "GPT base 0.137** (0.031) [practice] -0.054* (0.022) [exam]... Control arm mean 0.284/0.321. Control arm SD 0.287/0.277. Observations 2,848... Robust SEs are clustered at the classroom level." Prose: "in the subsequent unassisted exam, student performance in the GPT Base arm degraded by 0.054 (out of 1) relative to that of the control arm."

## Design facts

| field | value |
|---|---|
| design | RCT, randomized at classroom level (cluster-RCT), 3 arms; preregistered |
| n | main text states "nearly 1,000 students" total, ~50 classes; the specific figure 839 is not located verbatim in the extracted main text (main sample excludes honors-designated classrooms from the ~1,000 total) — 2,848 practice/exam observations at student-session level is consistent with roughly 839 unique students across ~3.4 sessions each, but this is arithmetic inference, not a quoted count |
| population | high school students (9th-11th grade), Turkey, Fall 2023-24 |
| instrument | closed-book closed-laptop exam mirroring practice problems, graded by rubric |
| delay-to-test | same 90-min session, immediately after the practice phase |
| effect size | GPT Base exam coefficient -0.054 (out of 1) / control-arm exam SD 0.277 = -0.195 SD ≈ claimed -0.19 SD; p<0.05 |
