## Claim as surveyed

"A structured AI-tutor protocol produced larger learning gains than in-class active-learning sessions in a randomized comparison." DOI 10.1038/s41598-025-97652-6.

## Primary text (quote, location)

Fetched: Nature/Sci Rep OA PDF via Unpaywall (`https://www.nature.com/articles/s41598-025-97652-6.pdf`). full_text_read: true (10 pages, pdftotext).

Abstract: "We find that students learn significantly more in less time when using the AI tutor, compared with the in-class active learning."

Results, p.2: "Students in the AI group exhibited a higher median (M) post-score (M = 4.5, N = 142) compared to those in the in-class active learning group (M = 3.5, N = 174). The median learning gains for students... in the AI-tutored group were over double those for students in the in-class active learning group... a statistically significant difference (z = -5.6, p < 10⁻⁸)."

Discussion, p.3: "While the linear regression suggests an effect size of 0.63, this... provides an effect size in the range of 0.73 to 1.3 standard deviations."

## Design facts (table)

| field | value |
|---|---|
| design | Randomized crossover; two groups, each experienced both conditions (AI at home, in-class active learning), reversed across two consecutive weeks |
| n | 194 analyzed (233 enrolled, Harvard Physical Sciences 2, Fall 2023) |
| population | Undergraduate physics students, life-sciences track |
| instrument | Pre-test/post-test on physics content (surface tension wk1, fluid flow wk2); FCI and CLASS survey for baseline |
| delay-to-test | None — post-test given same session immediately following the lesson (75-min period). Authors name retention testing (e.g., spacing) explicitly as unaddressed future work (p.4, "Context, limitations, and future directions") |
| outcome type | Assisted-context knowledge test scores, immediate; not a transfer task |
