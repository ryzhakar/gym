# N5-r4-01 — Verification

## Claim as surveyed

Among 238 OSS code reviewers (79% with >5 years dev experience), a reviewer's general coding experience (log of prior code changes) was the strongest positive predictor of code-review-comment usefulness in a regression model: "log RCE...has the highest level of influence with a positive coefficient...experienced coders...are more likely to provide useful comments."

## Primary text (quote, location)

Turzo & Bosu, "What Makes a Code Review Useful to OpenDev Developers? An Empirical Investigation," *Empirical Software Engineering* 29(1), 2024 (DOI 10.1007/s10664-023-10411-x). Full text obtained via arXiv preprint 2302.11686v2 (same title/authors, matches DBLP journal record `journals/ese/TurzoB24`; 24 pages).

p.14–15, §6.1.2 (Model analysis, Table 7 discussion):

> "Our model's parameter estimates suggest a total of five independent variables having statistically significant associations (p−value < 0.05... presented in bold format). Among those, log RCE (log of reviewers' coding experience) has the highest level of influence with a positive coefficient. This result suggests that experienced coders, who have significant project knowledge due to a large number of prior code changes, are more likely to provide useful comments."

Table 7: log RCE β=1.34e-01, 95% CI [6.90e-02, 1.99e-01], χ²=16.287, p=0.0001***. Highest χ² among the five significant predictors.

Quote matches verbatim. One imprecision: Table 6 defines RCE ("Coding experience") as "Number of files the reviewer has submitted in the codebase as an author" — a file count, not literally "log of prior code changes" (a change/commit count) as the claim's parenthetical states. The paper's own prose ("large number of prior code changes") uses the looser phrasing the claim borrowed; the formal operationalization is files-authored, not changes/commits.

## Design facts

| | |
|---|---|
| Design | Mixed-method: manual labeling of 2,500 CR comments (OpenDev Nova, Gerrit) + survey of developers + two regression models (LR for usefulness score, MLR for defect-category) |
| N | 238 survey respondents (response rate 7.49% of 3,178 delivered invitations); 2,500 labeled comments |
| Population | OpenDev (OSS) developers who submitted ≥5 code changes; 79% >5y software-dev experience; ~90% >2y practicing tool-based code review |
| Instrument | glm (R) linear regression, dependent variable = usefulness score derived from survey ratings mapped onto comment categories |
| Delay-to-test | N/A — cross-sectional, not a practice/test design |
