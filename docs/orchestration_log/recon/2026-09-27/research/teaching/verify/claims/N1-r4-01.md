# N1-r4-01 — Verification

## Claim as surveyed
RCT (n=69 GP residents): no significant difference feedback vs no-feedback on diagnostic-calibration (absolute accuracy p=.204; bias p=.176) for difficult cases.

## Primary text (quote, location)
DOI 10.1007/s10459-021-10080-9, full text (PMC 8938348).

"The analysis of calibration on all 12 cases, showed no effect of condition on absolute accuracy, F(1, 67) = 1.64, p = 0.204, η p² = 0.02 or bias F(1, 67) = 1.87, p = 0.176, η p² = 0.03." — Results, "Calibration accuracy and bias."

Abstract restates identically: "There was no difference between the conditions in the measurements of calibration (absolute accuracy, p = .204; bias, p = .176)."

## Design facts

| field | value |
|---|---|
| design | RCT, random assignment to feedback / no-feedback |
| n | 69 (feedback 34, no-feedback 35) |
| population | first-year general-practice residents, Erasmus MC Rotterdam (54 female, M age 29.29) |
| task | 12 diagnostic vignettes, confidence + mental-effort + complexity ratings per case |
| instrument | absolute accuracy (\|accuracy − confidence\|), bias (confidence − calibration) |
| delay-to-test | none — single session, same-day |

## Replications & critics
OpenAlex cited_by (search "replication"/"reanalysis"/"comment", n=8 hits): no direct replication. Closest related: 10.1007/s10459-023-10252-9 (Impact of performance and information feedback on medical interns' confidence–accuracy calibration) — different population (125 interns), different task (chest X-rays), two feedback types, delayed test phase; found both feedback types *improved* overall calibration (R²: 0.05→0.12/0.19). Not a replication of this design; flagged as a contrasting related finding, not a refutation (different task/design/population).
