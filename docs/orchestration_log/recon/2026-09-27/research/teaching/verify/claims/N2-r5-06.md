# N2-r5-06 — Verification

## Claim as surveyed
"As with transfer, the retention benefit of interleaved over blocked practice collapses in applied/field training settings: after sensitivity analysis the applied-setting pooled effect was negligible and briefly favored blocked practice, versus a large effect in laboratory settings." (DOI 10.1038/s41598-024-65753-3)

## Primary text (quote, location)
Full text (PMC11237090), Results, "Laboratory versus applied setting" subsection:

"The three-level mixed model analysis of random and blocked schedule retention test results in an applied setting... Sensitivity analysis revealed that after removing three outcomes... the pooled effect size decreased to negligible and favoring blocked practice SMD = −0.01 (95% CI: −0.35, 0.32; p = 0.94)."

Same section, laboratory setting: "The pooled effect size based on the three-level meta-analytic model was large SMD = 0.92 (95% CI: 0.48, 1.36; p < 0.001)... Sensitivity analysis... pooled effect size increased SMD = 0.93." Random-effects model gives SMD = 0.99 (lab) vs SMD = 0.35→0.30 (applied, non-significant even before the negligible three-level result). Discussion, later: "Analysis of applied studies turned out to be statistically insignificant, and the effect size was slightly above negligible (SMD = 0.23... and SMD = 0.28...)."

## Design facts

| field | value |
|---|---|
| design | subgroup analysis within the same PROSPERO-registered meta-analysis as N2-r5-05, splitting the 54 studies by laboratory (n=30 studies, 1210 participants, 89 effect sizes) vs applied/field setting (n=24 studies, 858 participants, 105 effect sizes) |
| n | as above |
| population | laboratory-setting tasks (sequential key-pressing, SRT, visuomotor, pursuit tracking, etc.); applied-setting tasks in natural environments (volleyball, golf, hockey, throwing, basketball, dance) |
| instrument | SMD/Hedges' g on retention-test performance, per-setting |
| delay-to-test | ≥24h in both subgroups (immediate-retention studies excluded from meta-analysis) |
