## Disagreements between sources (pairs, one line)

- N3-r3-06 (Hawthorne systematic review: most studies show *some* observation effect) vs. N3-r3-07
  (direct observer-present/observer-absent contrast: *no* effect once feedback is controlled) — not a
  flat contradiction: the review's own conclusion is that mechanisms and moderators are poorly
  understood, and N3-r3-07 is exactly the kind of controlled contrast the review says is rare; read
  together they suggest the "Hawthorne effect" often collapses to a co-intervention (feedback) effect
  when isolated, rather than pure observation per se — relevant to ruling 122's continuous-watching
  design question. Flag for Tier 4 if a synthesizer wants a firmer verdict; not resolved here.
- N3-r3-04 (human hints beat ChatGPT hints on learning gain, RCT) sits alongside r1's existing ledger
  claims on AI-tutoring guardrails (Bastani et al., Tutor CoPilot) as a third, independent data point
  that generic/ungated LLM content generation underperforms a structured or human-authored comparator
  on this specific axis — not a disagreement, a convergent pattern worth flagging to N7.

## Notes on method

Per-DOI Semantic Scholar (`api.semanticscholar.org/graph/v1/paper/DOI:...`) and Unpaywall were used
for every candidate DOI before any claim was written, per the round's tooling instructions (WebSearch
and OpenAlex budgets spent). All DOIs checked against `ledger/sources.csv` before appending; all 10
were new (not previously in the ledger under any need). arXiv's REST endpoint returned HTTP 406 for
several query forms via this environment's default HTTP client (urllib) but succeeded via
`curl -L` (following its http→https redirect) — worth a note for future rounds using this tooling.
