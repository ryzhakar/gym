## Disagreements between sources

- **PBL effect size, raw vs. corrected** (not a disagreement between two independent sources, but worth flagging as a within-source tension a synthesizer could otherwise miss): the meta-analysis (10.3389/fpsyg.2026.1868415) reports both an uncorrected d=0.529 and a publication-bias-corrected d=0.275 for the same underlying data — nearly a 2x difference depending on which number a later reader quotes. Recorded here per the project's own convention (cf. index.md's existing "performance vs. learning" disagreement entries) so a synthesizer cites the corrected figure, not the larger uncorrected one, without re-deriving this from the raw text.
- **Sequencing philosophy, unresolved and not adjudicated here**: this round's Reigeluth (general-to-detailed, N2-r6-08) and the SPM framework's whole-part-whole model (N2-r6-09/10) both prescribe starting from a version of the *whole* task before drilling parts, which sits in some tension with the existing index's already-flagged direct-instruction-first vs. productive-failure dispute (Sweller/Kirschner vs. Kapur, index.md `[education]` Disputes) and with the classic Gagné prerequisite-hierarchy view Reigeluth explicitly contrasts itself against. None of the three sources found this round are empirical head-to-head tests against each other; flagging the tension for Tier 4, not resolving it.
